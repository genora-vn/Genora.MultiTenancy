Bắt buộc lưu các cập nhật liên quan vào memory files và cập nhật MEMORY.md trước khi user bàn giao task tiếp theo.

**Why:** User cần continuity giữa các task và muốn trạng thái memory luôn mới tại thời điểm handoff.

**How to apply:** Mỗi khi hoàn tất task (hoặc khi user yêu cầu), cập nhật memory file liên quan trước, sau đó cập nhật MEMORY.md index rồi mới chuyển sang task kế tiếp.
