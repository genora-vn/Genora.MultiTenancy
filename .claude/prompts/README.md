# Prompts

> Thư mục dành cho custom prompt / prompt template tái sử dụng cho dự án Genora.MultiTenancy.

## Trạng thái hiện tại
**Chưa có custom prompt nào cho dự án này.**

Audit user-level không phát hiện prompt template riêng gắn với repo này.

## Khi cần thêm prompt
Đặt file `.md` tại đây, mỗi file một prompt template, kèm:
- Tên + mục đích
- Biến đầu vào (nếu có)
- Ví dụ sử dụng
