## Configuration model found
- PDF p8 explicitly names **Ngành hàng → Nhãn hàng → Sản phẩm**. Reuse HlgKnowledgeCategory for industry; add HlgBrand belonging to one industry; products reference industry and optional brand. No hard-coded business catalog.
- Product: general identity/thumbnail/summary; HTML product information; ordered FAQ knowledge; ordered media with image/video URL/poster and Hero/Information/Knowledge/Related placement; directional ordered related products; badge/game CTA/offer caption. Ordered content is a typed aggregate in DetailsJson, following existing ImagesJson storage; operator edits controls, not JSON.
- Games: name/description/list art/banner/badge/type/state/window; rich rules; question order/text/image/options/correct key/time/multiplier/base points. Fixed A–D option ordering retained; selected green option in PDF is not evidence of correctness.
- Ranking: event with optional game; ordered prize tiers referencing inventory rewards; operator-confirmed published winners with server-derived score/rank. No automatic award/deduction algorithm invented.
- Home: ordered banners and card slots; promotional copy, safe destinations/game link; Mini App share URL. Logo/background/chrome/native Zalo consent remain FE/platform configuration.
- Users: read-only admin profile/stats/learning/game/reward histories; retailer enum is additive value3 (Pharmacy1/Consumer2 retained); pharmacy code belongs to HLG profile, not golf customer identity.
